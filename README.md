# Инструмент визуализации графа зависимостей (Вариант 21)

## 1. Общее описание
CLI-приложение на Python для анализа зависимостей пакетов Ubuntu (APT).
На данный момент реализованы Этапы 1–4: интерфейс командной строки, сбор данных из локального репозитория, построение графа зависимостей с помощью рекурсивного DFS (с обработкой циклов) и вывод обратных зависимостей.

## 2. Описание всех функций и настроек
Программа поддерживает следующие параметры командной строки:
- `--package` — Имя анализируемого пакета (обязательно).
- `--repo` — URL-адрес репозитория или путь к файлу (обязательно).
- `--version` — Версия пакета (по умолчанию: latest).
- `--test-mode` — Включить режим тестирования (чтение локального файла).
- `--output` — Имя файла для сохранения графа (по умолчанию: graph.svg).
- `--ascii-tree` — Вывод зависимостей в виде ASCII-дерева.
- `--max-depth` — Максимальная глубина анализа (по умолчанию: 3).
- `--filter` — Подстрока для фильтрации пакетов.

## 3. Описание команд для сборки проекта и запуска тестов
Проект не требует установки сторонних библиотек (используется только стандартная библиотека Python 3).
Запуск осуществляется через `run.sh` или напрямую через интерпретатор:
```bash
python src/main.py --package A --repo tests/test_repo.txt --version 1.0 --test-mode
